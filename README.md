# yogapp-audio-de-katja

Unzipped de-katja voice clips for SynthYoga Cast receivers, served at
https://syntithenai.github.io/yogapp-audio-de-katja/v1/

Published by `apps/yoga/scripts/publish-voice-files.sh` in the yogapp repo.
The phone app downloads the same clips as a zip from
https://syntithenai.github.io/yogapp-audio-de-katja/v1/de-katja.zip
